# Working on krynn-pf2e

- Foundry VTT 14 module for the PF2e system (8.7+). The plan is docs/plan.md; versions follow its roadmap.
- `npm run check` must pass before a commit: strings in both languages, unit tests (tests/*.test.mjs, including the module running in the mock Foundry in tests/harness), module.json.
- Pure logic lives in scripts/logic (no Foundry globals, unit-tested); everything touching Foundry or PF2e lives in scripts/foundry.
- Every user-facing string goes through lang/strings/en.json and lang/strings/pt-BR.json; run `npm run lang` after changing them. Never write text copied from Dragonlance books or novels.
- module.json is generated by tools/build.mjs (homebrew registrations come from scripts/foundry/homebrew.mjs).
- Releases: bump the version in package.json and add a CHANGELOG section; pushing that to main publishes the release (tag, module.json, module.zip).
